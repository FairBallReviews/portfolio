# John-Scott W. Smith, Portfolio

Personal portfolio site for John-Scott W. Smith, Digital Strategy and Growth Leader.

Single static page, no build step. `index.html` is self-contained (inline CSS and JS, fonts from Google Fonts).

## Deploy

Hosted via Cloudflare Pages connected to this repository. Any push to `main` auto-deploys. The build command is left empty and the output directory is the repository root (`/`).

## Local preview

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```
